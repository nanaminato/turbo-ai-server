## 数据结构与升级

ModelKeyBinds 新增 `RoutingWeight double NULL`。保留 Fee 避免破坏旧客户端，不臆造币种、每 token 价格或真实扣费规则。

- 新库：使用更新后的 `merge/init.sql` 和 `open-initdata.sql`。
- 已完成架构升级的旧库：运行一次 `merge/routing-weight-upgrade.sql`，再运行 `merge/model-catalog-refresh.sql`。后者可重复运行；前者重复运行会报告重复列，需先核对实际结构。
- 更早版本：先完成 `architecture-upgrade.sql` 及需要的邮箱验证升级，再添加权重列。
- 启动只读校验结构，缺列会提示专用升级脚本，绝不自动修改数据库。

MySQL ALTER TABLE 隐式提交，不能依靠事务回滚 DDL。回滚应用前应导出显式权重配置；旧版本会忽略新权重，不应直接删除此列丢失配置。

更新密钥绑定时按当前密钥及 ModelId 匹配已拥有的绑定，保留绑定主键与熔断身份；新增才生成主键，移除才删除，拒绝同一请求重复绑定同一模型。不信任客户端提交的数据库关系图或路由 ID。

## 加权随机路由

`Priority` 数字越小越优先。仅在最优的健康、未排除的优先级内选择：

| RoutingWeight | 行为 |
| --- | --- |
| null / 未提供 | 兼容旧行为：Fee > 0 时取 1/Fee，否则取 1 |
| 0 | 不参与选择，可用于暂停路由 |
| (0, 1000000] | 使用显式相对权重，不再依赖 Fee |

例如同模型、同优先级的两条路由权重 1 和 3，健康时选择比例为 25% 和 75%；费用可独立记录为 0.2 和 0.8。优先级不同则不能这样计算比例。熔断或首个输出前失败后，会在剩余路由中重新计算；首个输出后不切换供应商。

Fee 目前是相对成本系数，不是用户实际账单。需要独立流量分配时应明确填写 RoutingWeight；只有兼容模式仍使用费用倒数。旧配置不强行回填权重，以保留既有客户端更新 Fee 的行为。

选择前过滤非有限值和非正权重，极小正费用的倒数饱和到最大有限数，同层权重先除以最大值再求和，避免总和溢出及最后一条路由偏置。禁用密钥不会进入普通路由或 ApiMart 池。

## 聊天会话亲和路由（2026-11-06）

聊天请求可传可选的 `conversationId` 字符串（最长 128 字符）。前端使用持久化聊天历史 ID，续聊、重新生成、刷新后保持一致。后端以已认证账户 ID + 会话 ID + 逻辑模型隔离绑定；账户 ID 来自登录声明，不能由客户端指定。会话标识仅用于本服务选路，不透传供应商。

首次请求、绑定过期或失效时，仍按上述优先级/权重选择。完整成功后保存路由绑定；后续优先复用健康的成功路由。首段输出前失败时排除该路由并重选，成功后覆盖绑定；已经输出、取消或未完成的流不会更新绑定，也不会拼接另一供应商的回答。成功切换的备用路由在原主路由恢复后仍保留亲和性，优先级和权重主要控制新会话或失效绑定的分配。管理员停用路由、权重设零，或者更改密钥、地址、供应商类型、上游模型后，旧绑定不能继续使用。

配置 `AiRouting:AffinityEnabled`（默认 true）、`AiRouting:AffinityMinutes`（默认 30，闲置分钟数，范围 1–1440）。这是本系统亲和记录的有效期，并非供应商缓存寿命。无需数据库迁移。设置 `AffinityEnabled=false` 可恢复逐请求加权随机。

复用现有 `IDistributedCache`：非开发环境且配置了 `ConnectionStrings:Redis` 时跨实例共享；开发环境或未配置 Redis 时仅单实例内存保存。缓存键为账户/会话/模型组合的 SHA-256，值仅保存路由 ID 和上游配置签名，不保存消息或明文密钥。缓存操作有 1 秒超时，读取/写入失败时记录警告并继续聊天。相同会话并发首轮可能独立选路，最后完整成功的请求更新绑定；不为路由优化串行化聊天请求。

保守地绑定具体路由，不假定不同渠道或 Key 共享上游缓存。会话亲和只提高前缀复用机会，不保证缓存命中。需要同时保持系统提示、工具和历史前缀稳定；新会话不应为追求缓存命中而复用旧会话 ID。

成功聊天记录 `AI chat routing completed` 结构化日志：路由、逻辑模型、是否复用绑定、切换次数、首个非空文本/拒绝输出延迟和总耗时。OpenAI / Alibaba 兼容适配器收到供应商 usage 时记录 `AI chat usage`：输入、输出、缓存读取、缓存写入 token 数；未上报的缓存写入为 null，不能当作 0。日志不包含消息、回答、会话 ID 或 API Key。未收到 usage 不臆造计费数据；第三方渠道实际折扣仍需核对账单。当前没有自动定价或预估账单功能。
