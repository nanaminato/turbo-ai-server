## SDK 升级：从 Betalgo.Ranul.OpenAI 完全迁移到 tryAGI.OpenAI 4.2.10

### 动机
- Betalgo.Ranul.OpenAI 9.2.6 不暴露 Verbosity / response_format 细粒度控制；
- Betalgo 的 `ChatCompletionCreateRequest.ReasoningEffort` 枚举仅 Low/Medium/High（无 None/Minimal/Xhigh），GPT-5 表达力受限。
- 用户选择"完全移除 Betalgo"（激进路线 C），用 AutoSDK 自动生成的 tryAGI.OpenAI 4.2.10 替换。

### 代码改动
- `Turbo.Auth.csproj`：删除 `<PackageReference Include="Betalgo.Ranul.OpenAI" ... />`，加入 `<PackageReference Include="tryAGI.OpenAI" Version="4.2.10" />`。
- `Application/Chat/OpenAiRole.cs`（新增）：从 OpenAiChatHandler 抽出共享常量 `SystemRole/Assistant/UserRole`（Google/Anthropic handler 也复用）。
- `Application/Chat/OpenAiChatHandler.cs`（重写）：
  - 构造 `new OpenAiClient(apiKey, baseUri: new Uri(baseUrl))`（SDK 自动 Bearer 鉴权）。
  - `client.Chat.CreateChatCompletionAsStreamAsync(request, cancellationToken:)` 返回 `IAsyncEnumerable<string>`。
  - `CreateChatCompletionRequestVariant2` 字段：`Messages / Model / Stream / Verbosity / ReasoningEffort / MaxCompletionTokens / FrequencyPenalty / PresencePenalty`。
  - `VerbosityEnum`（Low/Medium/High）→ `variant.Verbosity`；`ReasoningEffortEnum`（None/Minimal/Low/Medium/High/Max/Xhigh）→ `variant.ReasoningEffort`。
  - **重要**：`Variant2` 上**没有** `Temperature / TopP` 属性（4.2.10 OpenAPI spec 删除了），非推理模型通过 `AdditionalProperties["temperature" / "top_p"]` 兜底（标记 `[JsonExtensionData]`，会自动序列化）。
  - Vision 内容：显式 `new ChatCompletionRequestUserMessageContentPart(new ChatCompletionRequestMessageContentPartText { Text, Type })` / `(new ChatCompletionRequestMessageContentPartImage { ImageUrl = new ChatCompletionRequestMessageContentPartImageImageUrl { Url, Detail = Auto }, Type = ImageUrl })`，再用 `new ChatCompletionRequestUserMessage(new OneOf<string, IList<...ContentPart>>(parts), role, name: null)`。
- `Controllers/AI/OpenAI/MediaController.cs`（重写）：
  - TTS: `client.Audio.CreateSpeechAsync(model, input, voice, responseFormat, speed, cancellationToken:)` 返回 `byte[]`。
  - 自定义 voice：`VoiceIdsShared.FromVoiceIdsSharedVariant1(voiceString)` 配合 `VoiceIdsShared -> VoiceIdsOrCustomVoice` 的 `op_Implicit`；内置 voice 用 `(VoiceIdsShared)VoiceIdsSharedEnum.Alloy` 等。
  - Whisper 转写/翻译：分别用 `CreateTranscriptionRequest.Filename` 与 `CreateTranslationRequest.Filename`（注意拼写 `Filename` 不是 `FileName`），response format 用各自独立枚举 `AudioResponseFormat` / `CreateTranslationRequestResponseFormat`。
  - Image：`CreateImageRequestSize.x1024x1024`（无下划线）、`CreateImageRequestSize.x1024x1536` 等。
- `docs/technology.md`：AI SDK 行 `Betalgo.Ranul.OpenAI → tryAGI.OpenAI`。

### 关键 API 真相（4.2.10 本地版本与 GitHub main 分支不一致）
- `BetaVerbosity` / `BetaReasoningEffort` 类**只是占位 wrapper**（仅 `AdditionalProperties`），**不能**接受枚举值；不要用 `BetaVerbosityEnum`。
- `VerbosityEnum` / `ReasoningEffortEnum` 是 Variant2 上直接赋值的枚举类型。
- `ChatCompletionRequestUserMessageContentPart` 是 `partial struct`，**没有** `FromText` / `FromImageUrl` 工厂方法（`FromString` 写死 "describe the following image"，不能用作通用文本）。
- `List<ContentPart>.AsUserMessage()` **不存在**；扩展方法只支持 `string` / `byte[]`。Vision 必须显式构造 `ChatCompletionRequestUserMessage(OneOf<...>)`。
- `VoiceIdsOrCustomVoice.FromUnchecked` **不存在**；自定义 voice 走 `VoiceIdsShared.FromVoiceIdsSharedVariant1(s)` 隐式转换。
- 沙箱环境**反射被禁用**（PowerShell Add-Type 拒绝），最佳查 API 方式：直接 grep `tryAGI.OpenAI.xml`（NuGet 包内含完整 XML doc），看 `<member name="P:...">` / `M:...`。

## 后台支持前台「单次回复限制 (max_completion_tokens) 无限制」开关

### 前台契约（`turbo-user`）
- 设置页 `nz-switch` 控制 `isMaxTokensUnlimited()`。开启 ⇒ 请求体里**完全省略** `max_completion_tokens` 字段（不是 `null` 也不是 `0`）；历史配置中曾以 `0` 表示无限制，前端 `resolveMaxCompletionTokens` 已统一归一化为「缺失」。
- i18n key：`settings.maxTokensUnlimited` / `settings.maxTokensUnlimitedHint`。

### 后台改动
- `Controllers/AI/Chat/Models/NoModelChatBody.cs`：给 `MaxCompletionTokens` 加 XML 注释说明「无限制」语义（缺失=无限制，<=0 同样视作无限制）。
- `Application/Chat/OpenAiChatHandler.cs`：`if (HasValue)` → `if (... is > 0)`，并加注释。
- `Application/Chat/GoogleChatHandler.cs`（`BuildGenerationConfig`）：`if (HasValue)` → `if (... is > 0)`，并加注释。
- `Application/Chat/AnthropicChatHandler.cs`：Anthropic 的 `max_tokens` 是 API 必填字段，无法真正省略。新增常量 `UnlimitedMaxTokens = 8192`（覆盖 Claude 3.5/3.7/4 系列默认输出上限；模型自身上限更小时由 Anthropic 服务端截断）；`is > 0` 用用户值，否则用 8192。
- `AlibabaChatHandler / TwitterChatHandler`：DashScope 不暴露 max_tokens，无需改。
